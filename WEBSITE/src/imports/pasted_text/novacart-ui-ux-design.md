# NovaCart – Modern E-Commerce Website UI/UX

Design a **premium, modern, responsive desktop e-commerce website** called **“NovaCart”** for a CODSOFT UI/UX internship project.

The design should look like a **real-world professional e-commerce website**, not a basic student template. Use a clean, spacious layout with strong visual hierarchy, modern cards, consistent spacing, and polished UI components.

## Design System

* Primary color: **#2563EB**
* Background: **#F8FAFC**
* White: **#FFFFFF**
* Primary text: **#111827**
* Secondary text: **#64748B**
* Border: **#E5E7EB**
* Font: **Poppins**
* Border radius: **8–16 px**
* Use an **8-point spacing system**
* Desktop frame: **1440 × 1024 px**
* Use subtle shadows and clean borders
* Use high-quality product photography
* Maintain consistent alignment and spacing throughout

## Navigation Header

Create a reusable header component containing:

Use:

Animation duration: **300 ms**

Make navigation buttons, product cards, cart icons, and checkout buttons interactive.

## Overall UX Requirements

The website should communicate:

**Trust + Convenience + Modern Shopping**

Prioritize:

* Clear navigation
* Strong visual hierarchy
* Easy product discovery
* Clear CTAs
* Consistent spacing
* Accessible typography
* Professional e-commerce patterns
* Responsive-looking layouts
* Realistic product information

Avoid excessive gradients, excessive rounded shapes, clutter, unnecessary animations, or generic template styling.

The final result should look like a **portfolio-ready professional e-commerce website designed by a UI/UX designer**, suitable for submission as **CODSOFT Task 4**.
